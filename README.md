# Job Posting Pipeline

Personal job-posting monitor: scrapes a registry of companies' career pages via per-ATS adapters, normalizes and dedupes postings into Postgres, filters and alerts (Telegram) only on new matches, and has a Next.js dashboard for manual saved/applied/ignored tracking.

This repo is currently in the planning phase. The wayfinder map — the destination, the architecture decisions made so far, and the open tickets still being worked through before any code gets written — lives in [GitHub Issues](https://github.com/Subramani-the-dev/job-scraper-pipeline/issues), starting from the map issue labelled `wayfinder:map`.
